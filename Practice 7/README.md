# signup_form

Mobile Development, Practice 7: A Form That Validates Itself.

A sign-up form with `Form` / `TextFormField` validators, focus and keyboard
handling, a dropdown, a date picker, a checkbox-gated button, and an adaptive
summary card (`LayoutBuilder`).

## Run

This repo contains `lib/`, `pubspec.yaml` and lint config. Platform folders
(android, ios, ...) are generated by Flutter:

    flutter create .
    flutter pub get
    flutter run

`flutter create .` keeps the existing `lib/` files. Delete the generated
`test/widget_test.dart` if it complains.
